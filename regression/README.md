# Persistent regression suite

Every successfully minimized input generated by `spv targets run` is copied
here as `regression/<target>/<target>-<test_id>.input`, and an entry is added
to `regression/<target>/regression_tests.json`.

The orchestrator validates this suite on every run against the current base and
patched binaries, even when `--skip-reproducer` is used:

* the base version must still trigger the recorded error type and location;
* the patched version must not trigger it and must satisfy the recorded
  expected behavior;
* three replays are recorded for both versions;
* a test that no longer triggers on base, or still triggers on patched, is
  reported instead of being silently treated as a pass.

The suite is version-control friendly: inputs are small minimized files and the
manifest records the SHA-256, mode, arguments, expected patched behavior, and
finding signature.
